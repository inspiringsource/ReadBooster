# Browser-store badge sources

The images in this directory are used only as installation links in the root README.

- `chrome-web-store-badge.png` is Google's unmodified medium "Available in the Chrome Web Store" badge with a border for coloured backgrounds, downloaded from the [Chrome Web Store branding guidelines](https://developer.chrome.com/docs/webstore/branding). Its original dimensions are 340 × 96 pixels.
- `firefox-add-ons-badge.png` is Mozilla's unmodified 172 × 60 pixel "Get the add-on" button, downloaded from the Mozilla Add-ons Community Blog article [Promote your add-ons with the “Get the add-on” button](https://blog.mozilla.org/addons/2015/11/10/promote-your-add-ons-with-the-get-the-add-on-button/).

The README renders both images proportionally at 54 pixels high. The artwork itself has not been recoloured, cropped, distorted, or otherwise modified.
